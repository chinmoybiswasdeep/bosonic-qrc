# Tomography status

Exact truncated-Fock tomography is unsupported in the current CV implementation.
No Gaussian-state proxy, covariance-only reconstruction, or detector statistic
is labelled as exact tomography. A future implementation must declare cutoff,
probe family, measurement basis, optimizer, physicality constraint, fidelity,
reconstruction error, bootstrap uncertainty, and simulator-only validation
before the claim can enter the publication gate.
