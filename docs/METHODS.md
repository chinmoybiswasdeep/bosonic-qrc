# Methods

Closed spectra use fixed particle number and separate reflection parity for the open chain. Adjacent
spacing ratios use a fixed edge trim and bootstrap confidence interval; SFF and infinite-temperature
OTOC curves are saved independently. Candidate midpoint crossings are selected without any task
score. Ring Hamiltonians exist but are excluded from statistics until momentum resolution is added.

At each open step, the previous memory state is tensored with a fresh resource, input is displaced
only on that ancilla, entangling and PNR operations are executed, and only the retained modes pass
forward. Unconditional branches are weighted by their Born probabilities. Direct Kerr/Bose–Hubbard
memory and cat+cubic injection are separately labelled.

Task utilities implement NARMA10, delayed parity, Mackey–Glass, nonlinear channel equalization,
IPC-oriented delay features, and linear/RFF/ESN/NVAR controls. Splits are chronological with an
embargo, reset/washout per split, training-only preprocessing, validation-only ridge choice, and an
untouched test. IPC follows Dambre et al. [@dambre_2012].
