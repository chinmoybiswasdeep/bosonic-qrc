# Limitations

- Current chaos runs use open-chain reflection sectors; periodic translation sectors are not yet
  implemented.
- Smoke size, two cutoffs, and a single small open sequence are pipeline checks only.
- Direct multimode Bose–Hubbard evolution uses a documented local SciPy adapter after
  PhotoGraphiQ operations; the full path is not claimed to be backend-native.
- Photon addition/subtraction and conditional homodyne are audited backend capabilities but not
  selected in the present primary route. Cat+cubic injection is the implemented ablation.
- Full IPC/tasks, no/shuffled-feedback, passive, energy/rank-matched, finite-shot/noisy controls,
  Thouless inference, and trajectory-Lyapunov fitting remain calibration/production work.
