# Statistics

Reservoir seeds are independent units; data seeds are nested within them and
measurement seeds are a third level for finite-shot studies. Target rows are
not replicates. Hierarchical bootstrap intervals resample reservoir then data
seeds. Reports include mean, median, standard deviation, IQR, and 95% intervals.

Raw and FDR-significant capacity totals have separate rank-bound checks.
Confirmatory null inference requires `1/(B+1)<=q/M`; production additionally
requires `B>=4999`.
